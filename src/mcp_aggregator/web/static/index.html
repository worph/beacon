External MCP Servers

                

                    Add any HTTP MCP server (no Beacon SDK needed). Beacon will connect over streamable HTTP
                    to fetch the tool list and proxy calls through. Configs persist to disk.
                


                


                

                    
Add a server

                    

                        Paste the MCP endpoint. If it requires OAuth, Beacon registers itself with the remote
                        authorization server and you finish the login in a popup. If it turns out to be another
                        Beacon, its servers are imported individually instead of being nested behind its meta-tools.

How It Works

                
    
                    
  1. Beacon sends a UDP multicast discovery packet on the Docker network every 30s
    2. 
                    
  2. MCP servers with a discovery responder reply with their name, description, and tool list
    3. 
                    
  3. Beacon registers all tools with namespacing: {server}__{tool}
    4. 
                    
  4. Your LLM client connects once to Beacon and gets access to every tool from every server
    5.
